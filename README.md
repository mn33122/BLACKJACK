# Black Jack – C# Projekt

Gruppmedlemmar: David Almendariz
                Shadi
                Mohamd Nour
                

Denna projektet startar en BlackJack spel där du som spelaren kör mot en dator som spelar mot dealern.
Precis som Blackjack ska du försöka nå så nära till 21 som möjligt, gör man över är det blåst och då förlorar man.
För att köra projektet ska du ladda ner projektet som ZIP, extrahera filen och därefter kör programmet med IDE som Visual Studio eller ladda ner den via URL adress och kör den med IDE som kan köra C#.
Program.cs är programmets startfil. Den innehåller programmets startpunkt, där exekveringen börjar.

Vi som grupp arbetade bra, vi alla hittade våra roller och vad vi skulle göra. Vi kommunicerade via gruppchat, en person uppdaterade programmet medan en annan bygger vidare programmet.
Genom projektets genomgång har vi lärt oss mycket om klasser och deras uppbyggnader samt hur man kan organisera dem och kommunicera flera klasser med varandra. Samt har vi också lärt oss hur man använder git och github.
Det som var svårt speciellt i början var planeringen, vi hade inte mycket aning om vart vi skulle börja samt uppbyggnaden och planeringen av klasserna. Det som också var svårt har hur man skulle använda github och hur man skapar branscher, mergar, pusha och pulla.
Saker som vi kunde förbättra med projektet med mer tid hade varit att implementera grafik för att förfina utseendet av programmet. En annan sak om vi kunde implementara om vi hade lite mer tid var att implementara double och split funktionen inom BlackJack.
